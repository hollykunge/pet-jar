# 宠物罐 · macOS 0.5.3

三个 App 角色与多材质物体紧密堆叠在同一个透明玻璃罐里。点击 App 角色，就弹出对应消息框，投递目标固定为它对应的 App。

罐子为 260 × 260。玻璃外壳采用完整宽口罐轮廓，包含前后罐口、内外侧壁、厚底、柔和反光与边缘光学偏移。宠物堆和眼部表情受内壁遮罩约束，全部收在罐内。三个主角保持放大的比例，ChatGPT 使用用户参考图中的黄色圆角三角宠物，带黑色圆眼镜、闭眼表情和黑领结；黑色亮球和奶油色 Muse 保持原样，较小的材质物体填满周围空隙。当前使用整体生成的密集堆叠画面，数十个材质物体在统一光照下相互挤压、遮挡，带有连续的接触阴影。三个 App 角色按新可见轮廓拆成独立交互图层，三张脸错开、分别可点击。ChatGPT 对话框头像已同步替换。

## 外观与交互

- 玻璃壳横向收窄 10%，底部上收约 8 点，缩小罐壁与宠物堆之间的空隙；宠物堆大小、位置与眼部表情保持一致。
- 底部前景只绘制靠近观者的半圈厚底，去掉穿过宠物堆的后侧白色弧线和多余内沿线。
- ChatGPT：用户参考图中的黄色圆角三角宠物，戴黑色圆眼镜和黑领结。默认闭眼休息，悬停时睁眼回应。
- Grok Bot：按用户参考图改成黑色镜面亮球，带白色竖眼与明显的柔光箱反射。
- Muse：保留奶油色微笑脸与毛绒帽圈，身体压成团子形状、部分埋入物体堆中。
- 玻璃罐由原生绘图生成，整体堆叠底图、三个角色的轮廓图层、前景反光分别叠放。
- 占位材质包括镜面金属星、针织、苔藓与小雏菊、琥珀玻璃、幻彩玻璃球、斑点石材、胡桃木、彩色毛绒和钴蓝釉面。装饰图形不绑定 App。
- 只有三个 App 角色的可见轮廓可以路由消息；装饰区域不投递。
- 每只角色有独立点击区域，按整体图中的可见轮廓判断命中。
- 鼠标悬停时只改变眼部：ChatGPT 睁眼回应，Grok / Muse 眨眼；持续悬停每 2.8 秒再眨一次。身体、玻璃罐和堆叠始终固定，不位移、不缩放、不摇晃。移开后恢复原始表情。开启系统“减少动态效果”时仅保留静态眼部表情。
- 点击角色后，对话框显示该角色头像、对应 App 名称与发送目标；无需再选 App。
- 三个角色分别保留当前运行期间的草稿和投递方式。传送过程中锁定接收目标，避免中途切换。
- 拖动玻璃罐可移动；关闭或 Esc 收起对话框；⌥ Space 呼出上次角色。

## 使用

打开上一级的 `宠物罐.app`。本次构建适用于 Apple Silicon Mac，最低部署版本 macOS 14。

1. 在 ChatGPT、Grok Bot 或 Muse 中先选好要通信的智能体 / 会话。
2. 点击罐子里对应的角色，输入消息。
3. 已授权辅助功能时，可选择“填入并发送”或“填入当前会话”。未授权时，按钮明确显示“复制并打开”，需自行粘贴发送。

要启用直接填入，需要用户在 **系统设置 → 隐私与安全性 → 辅助功能** 中为“宠物罐”开启权限。程序只提供设置入口，不自行授予权限。App 当前尚未授权。

## 通信状态

| 能力 | 状态 |
| --- | --- |
| 点击角色 → 对应 App 对话框 | 已通过原生运行界面逐个验证 |
| 独立草稿、切换后恢复 | 已通过自测与原生界面验证，未出现跨角色草稿混入 |
| 复制文字并唤起对应客户端 | 沿用上一版已在三客户端验证的适配器；本次保留相同 bundle ID 路由 |
| 自动填入 / 点击发送 | 通用适配已实现，待辅助功能授权后逐客户端实测 |
| 指定某个 dot / Bot / Muse 会话 | 当前由用户在原客户端选择，尚未实现可靠会话绑定 |
| 把回复读回宠物对话框 | 尚未实现，回复仍在原客户端显示 |

ChatGPT 还可选择公开草稿链接 `codex://new?prompt=...`。这个入口预填新草稿，不自动发送，也不指定 dot。参见 [官方 Commands 文档](https://learn.chatgpt.com/docs/reference/commands)。

## 投递约束

适配器使用本机应用标识：ChatGPT `com.openai.codex`、Grok Bot `com.anysphere.sand`、Muse `com.meta.endo`。

直接填入时检查应用处于前台、输入框具有消息输入语义、目标草稿为空、焦点可确认。粘贴后回读文字，确认完全一致才继续寻找邻近且唯一的发送按钮。不盲按回车、不覆盖已有草稿、不自动重试。不确定时停止自动操作，并保留源草稿。

“已点击发送”仅表示系统接受了按钮操作，不代表服务端收到或任务完成。原型不调用模型 API，不读取客户端回复、不持久化消息正文。退出后草稿丢失；罐子位置保存在本机 UserDefaults。复制和粘贴会改变系统剪贴板。

## 构建与验证

需要 Xcode Command Line Tools，无第三方依赖和 API Key。

```bash
bash build.sh
```

脚本生成上一级 `宠物罐.app` 并本地签名，中间文件在工作区 `work/native-build`。

已验证：Swift 编译；整体画面打包；三个角色轮廓的点击命中与互斥悬停；装饰区域不投递；三个客户端的独立草稿；投递中目标锁定；Unicode / 换行 / URL 编码；消息框和发送按钮识别规则。此前版本已通过原生界面检查对话框、中文输入、草稿隔离与恢复；本版已通过三只宠物眼部表情的原生视图渲染与像素对比，变化仅在对应眼部区域；眨眼定时与移出取消通过自测。解锁后已在实际运行窗口核对黄色宠物睁眼，以及 Grok / Muse 的完整眨眼周期；桌面录帧对比确认眼部以外没有明显像素变化。眨眼周期使用开发预览悬停状态触发；普通鼠标命中与对话入口也已检查。没有向任何智能体提交测试消息。

仍待验收：实际自动填入与发送、会话身份绑定、回复回传、全局快捷键冲突、多屏拖动、重启后位置恢复。

## 源码与素材

- `Main.swift`：每角色草稿、绑定对话框、窗口与快捷键。
- `Jar.swift`：玻璃罐分层绘制、指针追踪与拖动。
- `PackedScene.swift`：静止整体底图、三个角色可见轮廓、点击命中及独立眼部表情。
- `Materials.swift`：保留的旧版独立素材布局，本版不参与构建。
- `Delivery.swift`：客户端路由、辅助功能通用适配、ChatGPT 草稿链接。
- `Resources/pet-chatgpt.png`、`pet-grok-glossy.png`、`pet-muse.png`：内置 imagegen 生成的角色，保留透明通道；属于本次原型素材，不是官方分发的原始角色图。
- `Resources/prop-*.png`：内置 imagegen 生成的八种材质素材，保留透明通道。
- `Resources/pile-scene.png`：内置 imagegen 按原始参考图和三角色素材生成的统一光照堆叠画面，是当前罐内主视觉。
- `Resources/pile-expressions.png`：内置 imagegen 生成的眼部表情参考帧，运行时仅采样六块眼部区域，其他像素不参与显示。
- `facial-expression-prompt.txt`：眼部表情参考帧的生成提示词。
- `cohesive-scene-prompt.txt`：本版整体画面的生成提示词与参考来源。
- `material-prompts.json`：本次黑球与材质素材使用的提示词。
- `asset-prompt.txt`：角色生成提示词及参考来源。

上一级 `宠物罐-面部表情预览.png` 是本版原生视图的离屏渲染；`宠物罐-运行截图.jpg` 为本版实际运行窗口；`宠物罐-桌面眨眼闭眼.jpg`、`宠物罐-桌面睁眼回应.jpg`、`宠物罐-桌面Muse眨眼.jpg` 为实际运行中的表情帧。
