# 宠物罐原型说明

当前产品为原生桌面宠物：透明玻璃罐、四种 AI 角色、双击打开客户端、悬停只读账号额度和眼部表情。Windows 使用 WPF / Win32，macOS 使用 AppKit，没有网页界面。

## 当前行为

- Windows 轻点宠物或装饰会推动物体，按住可拖动，松手后受重力并与其他物体 / 内壁碰撞；拖动空白玻璃或罐沿移动整个罐子。单击不打开窗口，宠物双击打开客户端。
- 晃动罐子时，内部物体按惯性相对玻璃偏移并碰撞，停下后继续运动再落稳；匀速移动不持续加力，程序找回与屏幕夹紧不产生额外冲击。
- 黄色眼镜领结 ChatGPT、镜面黑球 Grok、奶油毛绒 Muse、暖橘小螃蟹 Claude 共用场景坐标；Claude 使用独立透明素材。
- 悬停本身只改变眼睛，不给身体施力。物理运动时身体、眼睛与点击区域共享姿态，碰撞附带轻微视觉压缩 / 回弹；这不是软体网格求解。装饰物不绑定客户端，底部后侧白线不盖住宠物。
- Windows 右键提供宠物橱窗，可多选添加、移回并保存状态，每种最多一只。角色菜单保留打开客户端与绑定 / 额度来源。
- 消息输入框、写消息入口和自动投递功能已移除，原消息快捷键不再注册，不再请求辅助功能投递权限。

## 额度与素材

显示实际登录来源、周期、更新时间和可用的账号百分比，未知不记为 0，不以本机累计 Token 冒充账号额度。ChatGPT 对应本机 Codex 登录额度，Claude 对应本机 Claude Code 兼容来源；读取失败时显示不可获取。Grok / Muse 暂未接入真实额度。

Windows 物理场景使用 `Resources/pet-*.png` 独立角色和 `prop-*.png` 独立装饰，原生 Box2D 刚体求解，共 4 种宠物、26 个基础装饰与 28 个按空隙补入的小装饰。不同大小、前后遮挡和轻微接触阴影增加空间感，所有填充物均可交互。`pile-scene.png`、`pile-expressions.png` 和 `claude-eye-*.png` 保留给 macOS 静态场景与共享参考校验。素材和生成提示词保留在项目内。

Windows 执行 `./build.ps1 -Run` 或 `-Package`；macOS 执行 `make build` 或 `make package`。产物在 `dist/`，中间文件在 `.build/`，不依赖原对话目录。

Windows 构建执行几何、动态眼部像素、重力 / 碰撞 / 拖拽 / 快速抛掷 / 边界、交互与成员持久化自测，外观仍需真实窗口验收。macOS 源码已移除消息功能，当前 Windows 环境未编译或运行；Windows 橱窗与独立物理场景尚未移植到 macOS。详见 [Windows 适配说明](Windows适配.md)。
