# Windows 原生适配

入口 `Windows/Program.cs`，采用 C# / WPF / Win32。Windows 10/11，默认 x64 自包含单文件 EXE，资源全部嵌入。开发使用 .NET 8+，运行无需另装运行时。

```powershell
./build.ps1 -Run
./build.ps1 -Package
```

产物为 `dist/windows-win-x64/PetJar.exe` 和 `dist/宠物罐-Windows-win-x64.zip`。

## 当前交互

单击宠物不打开窗口，双击仅启动 / 激活客户端，未绑定时打开绑定窗口。双击须落在同一宠物，拖动、装饰和跨角色点击不触发打开。键盘聚焦宠物后，空格或回车也可打开客户端。

消息输入框、独立头像浮窗、写消息菜单、托盘对话入口、原消息热键、草稿状态、自动填入 / 发送与对应测试工具均已移除。启动不构造消息窗口，不注册 Alt+Space。程序不操作消息编辑器、剪贴板或发送按钮。

右键主菜单包含宠物橱窗、罐内角色、重新识别客户端、找回和退出。角色子菜单仅包含“打开客户端”和“绑定客户端 / 额度来源…”。托盘包含橱窗、找回和退出，双击托盘打开橱窗。`JarMenu.xaml` 提供乳白渐变、圆角白边、轻阴影、角色头像和浅绿高亮。打开菜单时收起额度浮层。

`BindingWindow` 独立保留有效 `.exe` 校验、已打开窗口选择与额度来源设置。旧设置中的会话标题筛选不再参与运行。

运行场景包含独立角色、26 个前排基础装饰、28 个前排小装饰及一排后方填充物，全部使用项目内透明素材，不再显示整体堆叠图。成员变更增删真实刚体和随动眼睛、无障碍按钮、命中、额度与角色菜单；移回正在拖动的角色会释放关节。添加时从罐内上部落下。物体姿态不持久化，每次启动自然堆叠，成员选择继续保存。

纵深采用两片物理截面的 2.5D 近似：前后排各自碰撞，与同一内壁碰撞，跨排投影允许重叠。后排按罐内面积的 68% 碰撞截面积填充，最多 160 个物体；不同材质形状自动调整数量。后排较小的碰撞截面允许投影遮挡，配合较低弹性和更强阻尼减少密集堆叠的持续弹跳。后排实体素材保持原不透明度，仅在其 alpha 轮廓上压暗光照，前排加强接触阴影；绘制和命中按同一深度排序。前景缝隙能选中真实后排物体，全部响应晃动。该方案不是三维刚体 / 深度移动，不使用固定背景填缝，也不通过降低整张物体的不透明度表现远近。

2026-10-20 纵深填充验收：Windows 构建、自测与 ZIP 打包通过。自测在四宠物混搭、单宠物针织、针织 / 苔藓和三种硬质组合中检查罐身采样覆盖超过 90%、后排暴露命中、分层碰撞过滤、共用内壁、抓取与无客户端路由；并重跑密集抛掷 / 晃动 / 有界形变。当前用户配置为单只 ChatGPT 和苔藓，离屏罐身采样（x=32..228、y=44..228、步长 4dp，按素材 alpha 命中）由前排 65.8% 提升为前后排 99.0%，包含 88 个后排实体；此数字为轮廓覆盖率，不是光学不透明度或整罐像素比例。实际 WPF 窗口确认透空减少，后排 `rear-84` 独立拖动并有 2.5% 轻微压缩、无客户端目标；两次移动罐子日志分别记录 124 / 58 个物体移动，松手后继续碰撞落稳。离屏预览与实际窗口分别验证，未改用户的宠物 / 填充物选择。

初始化先为四个角色保留容量，再用可见轮廓的距离场寻找空隙，优先填罐内中下部，逐个加入 12–22dp 的小装饰并自然落稳。大小变化、远小近大的固定绘制顺序、轻微轮廓重叠与缓存的原生接触阴影表现前后层次；绘制顺序也用于命中，填充物同样可拖动，不增加不可交互的装饰贴图。阴影随物体一起变换，不在每帧执行模糊滤镜。

260 × 260 的透明、无边框、置顶窗口。`JarGeometry.SceneRect` 为 `(25,8,210,210)`，对应 Swift 同一场景。`SceneLayout.json` 保存角色轮廓、眼部与 Claude 位置，构建校验 Swift 几何和眼部图源 SHA-256。玻璃和内壁共用 `(0.90,0.967)` 变换，后侧白线不盖住宠物。

`JarPhysicsScene` 使用固定的纯托管 `Box2D.NetStandard 2.4.7-alpha`，120Hz 固定步长、8 次速度 / 4 次位置迭代，限制单帧追赶以防窗口恢复时跳跃。内壁直接展平 `JarGeometry.Interior`，沿轮廓向外建立实体碰撞带；密集接触耗尽位置修正预算时，穿界物体只退回上一个固定步长中的有效姿态并消散速度。角色和装饰使用圆、凸多边形或复合碰撞形状。鼠标关节抓取原点击位置，限制拖拽目标和松手速度；连续碰撞检测防高速穿透，刚体静止后睡眠。源码构建强制开启优化，第三方许可与产物一起分发。该依赖为预发布版本，已用项目自测覆盖本场景，升级须重跑物理与原生验收。

轻点任何物体施加推动；拖动宠物或装饰会带动周边物体，松手按重力下落、摩擦碰撞后重新堆叠。拖动未命中物体的玻璃区域移动罐子。主键与次键均可拖动，次键原地点击仍打开菜单；拖拽不会当成宠物双击。丢失捕获、失焦、关闭或移回宠物都会清理鼠标关节。装饰没有客户端路由。

整罐移动使用 `JarMotion`，每个合成帧采样实际窗口 DIP 位移，平滑并限制速度，按速度增量给罐内每个刚体施加与质量成正比的反向冲量。起步、改变方向和停下均有惯性，匀速拖动不持续注入能量。松开只结束输入，不丢弃尚未渲染的最后一段位移；快速拖动同样响应，随后继续通过重力、摩擦和碰撞落稳。屏幕夹紧只平移采样基点，找回 / 隐藏重置历史，超过 200ms 的帧停顿重新采样，避免程序移动或卡顿产生异常冲击。hover 与单个物体拖拽不作为整罐移动输入。

`MaterialSquash` 使用有限的局部方向性应变：横向受挤变窄、向上下鼓起，竖向或斜向受力也沿对应方向响应。ChatGPT、Muse、Claude 毛绒最多压缩 9%，针织最多 6.5%，植物纤维最多 4.5%；镜面黑球、金属、石头、木头、蓝色硬质与琥珀保持刚性，泡泡只有少量弹性。接触冲量换算成持续压力，缓存最后一次求解结果直到接触结束，因此刚体睡眠后仍保留静态压痕；移回宠物时清理压力缓存。按住主键就有轻握反馈，拖动两种鼠标键均支持抓取受压，松开 / 丢失捕获 / 失焦解除，阻尼恢复原形。hover 只影响眼睛，不创建抓握或冲击。

这是刚体碰撞加有限视觉形变，不是软体网格求解。`PhysicsJarDrawing` 中身体、眼部贴片和 alpha 命中共享同一含压缩 / 侧鼓 / 斜向形变的物体变换，移动、旋转或压缩不会错位。玻璃绘制保留原生材质与前后分层，不反射旧的烘焙角色。`JarDrawing` 保留为共享静态参考与 macOS 眼图导出工具。

待机自然眨眼，ChatGPT 偶尔缓缓睁眼；悬停睁眼回应、眨眼或眨单眼，不因 hover 给身体施力。局部材质覆盖原眼睛，闭合时切换眼形，避免残影。系统禁用客户区动画时使用静态表情，直接操作和重力仍正常完成；隐藏或关闭时取消帧回调。

## 客户端和额度

`ClientDiscovery` 检查卸载记录、常见目录和已注册 Store 包，核对产品、发布者与主入口。有效手动绑定保留，自动 Store 绑定随升级刷新路径并保留 AUMID；CLI、Cursor 和无关同名软件不得误绑。

`ClientLauncher` 仅启动或恢复 / 激活匹配程序，有窗口时优先使用，无窗口时通过包身份或 EXE 启动。前台句柄一致才报告已打开。未识别或有歧义时手动绑定，不自行提权。

额度异步只读，每 45 秒刷新。ChatGPT 为本机 Codex 订阅额度；Claude 为本机 Claude Code 兼容来源，登录无效时不可获取、不自动更改凭据；Grok / Muse 暂未接入。显示来源、周期和更新时间，未知不记为 0，过期不沿用旧百分比。凭据不写入设置或报告。

悬停浮层为 254dp 宽的原生材质卡片，与菜单共用乳白渐变、18dp 圆角、白色描边和轻阴影。头像旁显示角色与实际登录来源；主体只显示周期、剩余百分比、对应的圆角余额条与重置时间，底部显示更新时间。未绑定时只加小标记；读取失败显示简短原因，不展示虚构比例；旧结果明确标记刷新失败与上次时间，过期周期不显示旧百分比。重复的已用比例、Token 解释和双击提示不再堆在卡片里。浮层不接收点击，不触发客户端打开。
